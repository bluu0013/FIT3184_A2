Proposed architecture

AWS handles identity, API, storage, data and chat. GCP runs the ML inference. The cross-cloud link carries the Cognito token, which the GCP function verifies. This is a starting point to agree on in week 0, not a final design.

flowchart LR
  U[Browser UI] -->|sign in| COG[AWS Cognito]
  U -->|JWT| APIGW[AWS API Gateway]
  APIGW --> LQ[Lambda: query, tags, delete]
  U -->|upload| S3[(AWS S3 media)]
  S3 -->|event| LT[Lambda: thumbnail + dedup]
  S3 -->|event| LI[Lambda: ingest]
  LI -->|JWT forwarded| GCP[GCP Cloud Run: YOLO / MegaDetector]
  GCP --> GCS[(GCS model weights)]
  LI --> DDB[(AWS DynamoDB)]
  LQ --> DDB
  LI --> SNS[AWS SNS email alerts]
  LEX[AWS Lex chatbot] --> LQ
  U --> LEX

Rules from the spec

  • At least two cloud providers, with cross-cloud calls shown and justified in the demo.
  • Cognito for auth. Everything except sign-up is blocked when signed out.
  • Video: 1 frame per 10 seconds.
  • File-based search must not store or index the query file.
  • Everyone commits to the private repo, shared with the teaching team.
  • All members attend the Zoom demo: 3 min architecture, up to 15 min demo, then Q&A.
  • Peer assessment can cut up to 50% from a member's mark.
  • AI use is allowed but must be acknowledged, and you must be able to explain your code.
